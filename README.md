# 贪吃蛇

经典贪吃蛇游戏，单个网页文件即可运行，手机和电脑都能玩。

## 在线链接

- 试玩：https://hanweichou162-bit.github.io/snake-game/
- 仓库：https://github.com/hanweichou162-bit/snake-game

## 玩法

- 电脑：方向键或 WASD 移动，空格暂停，回车重新开始
- 手机：在画面上滑动改变方向，或点屏幕下方的方向按钮
- 吃到红色食物得分，蛇越长移动越快；撞墙或咬到自己游戏结束
- 难度：简单 / 普通 / 困难，点按钮切换并直接开一局（选择会自动保存）
- 双人对战（仅电脑）：P1 绿色用 WASD，P2 蓝色用方向键，撞墙或撞到蛇就输；双人得分不计入最高分
- 最高分保存在浏览器本地
